# QR Code Scanner App

A Flutter application that uses the device's camera to scan QR codes and displays the decoded text.

## Features

*   Camera permission handling
*   QR code scanning
*   Displaying scan results

## Dependencies

*   qr_code_scanner: ^1.0.1
*   permission_handler: ^11.1.0
*   provider: ^6.0.0

## Getting Started

1.  Clone the repository.
2.  Run `flutter pub get` to install dependencies.
3.  Run `flutter run` to start the application.

## Permissions

This application requires camera permissions.  The app will request these permissions when necessary.
